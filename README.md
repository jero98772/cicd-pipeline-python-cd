# cicd-pipeline-python-cd

Calculadora web en Python (Flask) con un pipeline de CI/CD en GitHub Actions:
pruebas, analisis en SonarCloud, imagen Docker publicada en Docker Hub y
despliegue continuo en AWS ECS (Fargate) con Terraform, primero en Staging y
luego, con aprobacion manual, en Produccion.
